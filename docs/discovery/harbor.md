# Harbor as an eval runner (RX1)

Harbor runs agent trials in task-defined environments and grades their outputs. I read the public [harbor-framework/harbor repository](https://github.com/harbor-framework/harbor) at `v0.27.0`, commit `96c86af3bc6d7e92f21fc771d21273be4714c8e9`, including the source and the documentation at that pin. The project is `Apache-2.0` under its [LICENSE](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/LICENSE). This was a source review. Runtime claims about an OpenWiz integration are unverified. [Harbor README](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/README.md)

## Skills gate

Harbor can run *under* the skills gate. A task provides instructions, a task configuration, an environment and a verifier that produces a numeric reward. A job can load a skill directory from a local checkout and records the content digest in its lock. A custom agent can register the skill and supply its own tool boundary. This covers the trial environment and collection of results. [Task format](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/overview.mdx), [job skills](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/jobs/skills.mdx), [custom agents](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/agents/custom-agents.mdx)

WizSkills would still own per-skill coverage, the fake tool world, case scoring, base/head pairing with equal model and repeats, the tolerance, the opt-in key check, and the distinction between a skip and a pass. A general shell inside a container does not reproduce the fake tool's canned replies or its ordered event log. An adapter would need to preserve that log and report a runner error separately from an agent failing the case. Treating Harbor's aggregate reward as the release decision would omit those requirements. [Skills gate #3443](https://github.com/openwizdev/OpenWiz/issues/3443), [current fake tool and scoring contract](https://github.com/openwizdev/OpenWiz/blob/3a74aff0e0257d3a639a7a59f834a3b40fccbf89/tools/skills-eval/contract.md), [Harbor job configuration](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/src/harbor/models/job/config.py)

## GitHub Actions

A keyless fixture job looks feasible from source. Harbor defaults to Docker and accepts a prebuilt task image. Its Oracle agent runs a supplied solution script without model inference. It can smoke-test the verifier, while a custom fake agent is needed to exercise the proposed skill-to-scorer integration. GitHub lists Docker and Compose on `ubuntu-24.04` and offers standard hosted compute for public repositories without a paid runner. A public, digest-pinned image and preloaded fixtures would avoid Harbor Hub, cloud sandbox accounts and model keys. [Docker default](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/src/harbor/models/trial/config.py), [environment docs](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/environment.mdx), [Oracle source](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/src/harbor/agents/oracle.py), [Ubuntu runner image](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md), [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions#how-use-of-github-actions-is-measured)

For CI reproduction, pin Harbor, its resolved packages, the task and verifier images and inputs, and the skill and agent versions. Record the hosted runner image version and the resolved Harbor locks. The task environment can also be opened interactively with `harbor task start-env` for local inspection. Container pins help reproduce the runtime and inputs. Hosted runner kernel compatibility and repeatability of an agent's answers are unverified. Harbor's own runtime workflow uses a separate VM for runtime tests needing kernel features, so that workflow is weak evidence for running all of Harbor's options on a stock runner. [Harbor lock](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/src/harbor/models/job/lock.py), [environment setup tutorial](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tutorials/create-a-task.mdx), [upstream runtime CI](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/.github/workflows/pytest.yml)

Harbor's own usage telemetry is enabled by default and is sent from the host. Its documented setting is `HARBOR_TELEMETRY=off`. Docker's no-network policy controls the task containers, so any future OpenWiz integration would also need to verify host egress and withhold credentials from both the fixture and the host process. No-secret execution here means a fake/model-free trial. The opt-in with the chosen model provider still governs real skill scoring. Secret-free execution and off-by-default behaviour of the combined setup are unverified. [Telemetry docs](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/telemetry/telemetry.mdx), [telemetry source](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/src/harbor/telemetry.py), [container network policies](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/network-policies.mdx), [privacy spec #3456](https://github.com/openwizdev/OpenWiz/issues/3456), [skills gate #3443](https://github.com/openwizdev/OpenWiz/issues/3443)

## Factory bench

Harbor can describe a fixed public terminal dataset with instructions, starting files and offline judges. A local manifest can select pinned task directories. The bench should still record each task's original commit and licence independently. [Dataset definition](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/datasets/create-a-dataset.mdx), [task format](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/overview.mdx), [factory bench #3712](https://github.com/openwizdev/OpenWiz/issues/3712)

The planned benchmark measures the OpenWiz fleet through disposable repositories, tickets, builds, reviews and merged PRs. A normal Harbor trial measures its configured agent. Harbor could later package an offline judge after the bench has found a verified merge, using the merged tree as verifier input. Bench ownership of the merge proof, attempts, wall time, tokens, task-set hash and release comparison would stay with #3712. Judge parity on actual merged trees and equivalent usage records are unverified. [Factory bench #3712](https://github.com/openwizdev/OpenWiz/issues/3712), [Harbor task and trial model](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/overview.mdx), [verifier artifact inputs](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/artifacts.mdx)

## Licence and maintenance

The proposed listing vendors no code or images. For a later vendoring decision, the pin's runtime requires Python 3.12 or newer. The lock includes `harbor-framework-client` 0.3.0 (`Apache-2.0`), Pydantic 2.14.2 (`MIT`), and LiteLLM 1.93.0 (the package declares `MIT`, with separate commercial features identified by its maintainers). The licences and notices of the full transitive set, optional providers, benchmark tasks, and Docker image packages are unverified. A future vendoring review needs to enumerate and check the exact subset shipped. ## Decision

Harbor's published licence and local task support make it suitable for an optional listing. The skills gate and factory bench already specify semantics beyond environment setup and numeric rewards. Adding Harbor now would require a second runner, an adapter to preserve those semantics, and an egress and parity proof that the sources cannot supply. [Harbor licence](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/LICENSE), [local environment docs](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/tasks/environment.mdx), [Harbor telemetry](https://github.com/harbor-framework/harbor/blob/96c86af3bc6d7e92f21fc771d21273be4714c8e9/docs-mintlify/telemetry/telemetry.mdx), [skills gate #3443](https://github.com/openwizdev/OpenWiz/issues/3443), [factory bench #3712](https://github.com/openwizdev/OpenWiz/issues/3712)

**Verdict:** listing-only.
