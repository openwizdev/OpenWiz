# Fleets ship as skills first, then as OpenWiz code

0.0.5 ships fleets as Markdown skills any orchestrator can run today; 0.0.6 builds the same steps into OpenWiz itself, and 0.0.5 is accepted by planning and building 0.0.6 with its own skills. Skills first tells us what the code really needs, the way 0.0.1's live spike did for the reads. We adapt Matt Pocock's skills (MIT) rather than starting from nothing, and combine his to-spec and to-tickets into one plan-graph skill.
