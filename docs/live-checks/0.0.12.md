# 0.0.12 live-check kit: index

The bounded live check for 0.0.12 (spec #1092's CP8) is the final person's ticket, run under [ADR 0016](../adr/0016-agents-run-live-tests.md) from a Local thread on the PC ([ADR 0015](../adr/0015-live-tests-on-the-pc.md)) after the version-level permission. **Nothing here is permission to run anything live.** This index is shared; each action's steps are in its own part.

## Caps (whole kit)

At most **two sends** (one Needs you answer, one message) and **one create**, on pre-existing designated throwaway threads and one throwaway project; no attachments, other targets, retries, merges, tags or publishing. If a suitable target is missing, stop and revise the kit.

## Order

1. **Discovery first (read-only):** the installed `openwiz --version`/`room-cli` shapes, the server's configured port and allowed host, as the live-spike skill says. No endpoint claim before this.
2. **Explicit JSON reads:** `openwiz help --agent`, `openwiz ls --json`, `openwiz fleets --json`, `openwiz ui --json`.
3. **Terminal read path (this part, T3):**
   - `openwiz ui --port <the server's port>`: Home shows Needs you, fleets and sessions, each with its coverage and read age; `s` and `f` open Sessions and Fleets; Enter opens a detail; Esc returns.
   - Resize the window small and back: navigation stays; `q` quits; the shell prompt works normally (no raw mode, cursor visible).
   - Run `openwiz` with no arguments in the terminal: the same Home. Quit with Ctrl-C: the terminal is restored.
   - Record counts only: zero writes in this part.
4. **Action parts, each only once shipped and within the caps above:**
   - Answer one synthetic Needs you item: [0.0.12-parts/answer.md](0.0.12-parts/answer.md)
   - Send one message: [0.0.12-parts/send.md](0.0.12-parts/send.md)
   - Start one Cloud thread: [0.0.12-parts/new-thread.md](0.0.12-parts/new-thread.md)
5. **Read back** every operation's recorded outcome. Accepted/created is not completed/started; any uncertainty stays a gap.

## Quick Mac check

On the Mac only: the installed `openwiz ls` and `show` (read-only) and, where available, a read-only `openwiz ui` launch and quit. A few minutes, no writes. Unavailable coverage stays unverified; PC or CI proof is never relabelled Mac proof.

## Records

Store only the tested head/tree, counts, sanitized observations and remaining gaps; no live identifiers, prompts, transcripts or credentials.
