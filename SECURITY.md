# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/openwizdev/OpenWiz/security/advisories/new). Never report a vulnerability in a public issue.

We'll acknowledge your report within 3 business days and work with you to coordinate a fix and disclosure.

## Scope and supported versions

This policy covers the OpenWiz kernel, command-line tool, and adapters.

We support the latest release and the `main` branch.

The site's [security.txt](https://openwiz.dev/.well-known/security.txt) points to the OpenWiz advisory page.
