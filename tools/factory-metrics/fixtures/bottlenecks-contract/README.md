# Synthetic EB5 fixtures

`synthetic_assumptions`: all future record shapes, timestamps, revisions, hashes,
model settings, evidence links, usage, review attestations, power inputs and
outcomes here are invented contract examples. Nothing was observed live.

- accepted.json: compatible frozen arms, three independent rounds separate from
  one self-check, sourced 18-hour timing, immature/unknown defect coverage,
  separate CF4 input/results, no live approval or assignment, credit gaps.
- attribution-resolution.json: later causal evidence resolves an original
  unknown root cause without rewriting or duplicating its observation.
- preregistration.json: complete numeric protocol fragment, experiment-bound and
  composed with the paired replay/CF4 references by the owning test.
- unrun.json: no prepared protocol, assignment, replay or live result.
- unfinished-result.json: one assigned open ticket, no candidate assignment,
  unknown effects and an inconclusive result. Its all-zero hash slot is filled
  with the explicit protocol reference by the owning test.

The owning test composes these literal fragments with the existing journey and
replay fixtures. Its negative tables are the refusing fixtures: guessed dates,
helper/duplicate rounds, immature certainty, incompatible/failed CF4, leaked or
late answers, unequal contexts, partial scores, absent totals, incomplete power,
mutable assignment/protocol and unsupported operation. No test reads private
files. Canonical hashes cover invented values, not evidence of real execution.
