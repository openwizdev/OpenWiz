Claude Code's effort option. The first part is copied from the installed CLI on 2026-11-24; the second from its published reference.

$ claude --version
2.1.331 (Claude Code)
$ claude --help   (its effort lines; ultracode is not in it)
  --effort <level>                      Effort level for the current session
                                        (low, medium, high, xhigh, max)

CLI reference (https://code.claude.com/docs/en/cli-reference) and model configuration page (https://code.claude.com/docs/en/model-config), read 2026-11-23:
ultracode requests xhigh effort with ultracode turned on, and requires Claude Code v2.1.203 or later.
CLAUDE_CODE_EFFORT_LEVEL: first in the order Claude Code resolves the session's effort level, ahead of --effort.
If you set a level the active model does not support, Claude Code falls back to the highest supported level at or below the one you set.
