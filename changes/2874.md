kind: security

`agent-token.py` now saves a new token in its owner-only private folder, recreating the folder if it was deleted during the mint, before it asks GitHub to revoke that token, so a refused revoke leaves a copy that a later `revoke` or mint finds and revokes; after a refusal it checks the copy is still there, writing it again if needed, and says to suspend the installation when it cannot, as tested against a fake GitHub API.
